# global_fracture_porosity

Jupyter notebook to  estimate the global effective fracture porosity and fracture density in crystalline rocks from permeability data, used in *van den Berg et al. (2026)** – *A global assessment of effective fracture porosity and density in crystalline rocks* 

## Overview
We estimate effective fracture porosity and fracture density from a global dataset of ~28,000 permeability measurements.

The workflow includes:
- Deriving porosity from permeability using a modified Snow (1968) approach
- Incorporating fracture roughness and depth-dependent aperture
- Monte Carlo uncertainty analysis- Statistical analysis of porosity-depth relationships

## Requirements
- Python (>=3.9)
- numpy, pandas, matplotlib, scipy
